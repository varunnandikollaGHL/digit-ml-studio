## a. Problem statement

Classify 8×8 images of handwritten digits (0 through 9) from their 64 grayscale pixel-intensity features. Compare Logistic Regression, Decision Tree, K-Nearest Neighbors, Gaussian Naive Bayes, and Support Vector Machine on **the same stratified holdout**. Evaluate all six assignment metrics, save the fitted classifiers and build an interactive Streamlit application that loads saved models and scores uploaded labeled test CSVs **without retraining**.

## b. Dataset description

- Public origin: [UCI Optical Recognition of Handwritten Digits](https://archive.ics.uci.edu/dataset/80/optical+recognition+of+handwritten+digits) (Alpaydin & Kaynak, 1998, [DOI](https://doi.org/10.24432/C50P49)).
- This project uses scikit-learn's bundled `load_digits()` subset (**1,797 rows** from the original UCI test portion), **not** all 5,620 records in the original UCI release.
- **Features:** 64 numerical pixel intensities (0–16), named `pixel_0_0` ... `pixel_7_7`; minimum 12 features satisfied.
- **Target:** `digit`, integer multiclass label 0 through 9. There are no missing values.
- **Split:** 1,437 training / 360 testing observations, `train_test_split(test_size=0.20, stratify=y, random_state=42)`.
- Test CSV `test_data.csv` includes 64 features **plus** the `digit` target; `full_dataset.csv` records the source observations.

## d. Models and six-metric comparison

All five models fit exclusively on the training partition. Scalers for Logistic Regression, KNN and SVM are stored inside `sklearn.pipeline.Pipeline`. Models are serialized with Joblib to `model/`.

| Decision Tree | 0.8194 | 0.9105 | 0.8209 | 0.8194 | 0.8176 | 0.7999 |
| K-Nearest Neighbors | 0.9667 | 0.9950 | 0.9675 | 0.9667 | 0.9664 | 0.9631 |
| Gaussian Naive Bayes | 0.8333 | 0.9719 | 0.8574 | 0.8333 | 0.8368 | 0.8171 |

*Reference scores from the existing local run (not from BITS Virtual Lab).* Precision, recall and F1 are weighted multiclass averages; AUC is multiclass weighted OvR and MCC is multiclass Matthews correlation coefficient. Uploaded test files must contain all ten classes for AUC to be defined.

### Model performance observations

| Model | Observation |
|---|---|
| Logistic Regression | 97.22% accuracy; strong linear baseline with scaling; 0.9991 AUC. |
| Decision Tree | 81.94% accuracy; lowest score; threshold splits can overfit individual pixels. |
| KNN | 96.67% accuracy; captures local similarities in digit images; stores training examples. |
| Gaussian Naive Bayes | 83.33% accuracy; neighboring pixels violate its conditional-independence approximation; AUC remains relatively high. |
| SVM | **98.06% accuracy and 0.9784 MCC**; nonlinear RBF kernel works well on this feature space. |
| Overall winner | **SVM** on this specific held-out test split, ranked by weighted F1. |

These findings do not establish a universal ranking; repeated cross-validation could improve confidence.

## e. Streamlit frontend features

1. Upload a labeled **test** CSV with all 64 input features and the `digit` column.
2. Select among five pre-trained models using a dropdown.
3. View **Accuracy, AUC, Precision, Recall, F1 and MCC** recalculated from the uploaded test set.
4. Inspect a **confusion matrix** and ten-class classification report.
5. Compare all five models on identical uploaded rows.
6. Preview an 8×8 digit image, true label, predicted label and predicted probabilities.

The app only calls `joblib.load`, `predict` and `predict_proba`; it **does not refit** on uploads.
